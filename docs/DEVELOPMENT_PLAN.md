## 验证范围

`npm test` 验证规则、AI、导入局面、图像识别、镜头、IK、人物动作、动态分辨率和存局校验。测试通过不等于所有算法都有 100% 覆盖。

`npm run smoke` 覆盖开始页、导览、选边、落子、人物携子、暂停、悔棋、提示、记谱、终局、再战、图片复原与 AI 续下。

`npm run test:features` 覆盖真实鼠标及触屏事件、复盘期间计时不变、历史淡子清理、动画队列取消、390×844 手机菜单和刷新后的继续棋局。

`npm run test:production` 将构建产物挂载在 `/Zenith-Tabletop-3D/`，检查模型、纹理、字体、Worker、AI 落子及资源请求。

## 产品边界

当前是本地单人对 AI 的五子棋应用。局面导入用于继续尚未结束的对局；已结束的棋局可在当前对局中复盘。未实现多人联网、账号云同步、围棋或原生移动安装包。可选远程导师需要部署者配置，默认对局不依赖远程推理。

性能取决于设备和画质；动态分辨率与自动画质会优先保持交互可用，不承诺所有 GPU 固定 60 FPS。
