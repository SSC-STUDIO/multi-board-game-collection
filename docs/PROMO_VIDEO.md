# 竖屏宣传视频

面向手机观看的 9:16 宣传片，1080×1920，H.264 / AAC，30 fps 输出。另导出 720×1280 分享版、JPG 封面、SRT 字幕、JSON 棋谱与验证报告。成片约 1 分 54 秒，包含从空棋盘到黑方五子连珠的完整 21 手对局。

## 重新制作

需要 Node.js 22.12+、Chrome / Edge、FFmpeg 与 ffprobe。录制使用本地 GPU；中文字体采用系统微软雅黑或 Noto Sans CJK SC。先执行 `npm ci`，然后：

```sh
npm run video:capture
npm run video:encode
npm run video:verify
```

输出位于 `artifacts/video/`：

- `Zenith-Tabletop-3D-Mobile.mp4`：1080p 高清成片。
- `Zenith-Tabletop-3D-Mobile-Share.mp4`：720p 分享版。
- `Zenith-Tabletop-3D-Mobile-Cover.jpg`：竖屏封面。
- `Zenith-Tabletop-3D-Mobile.srt`：字幕副本；画面本身已含字幕。
- `complete-game.json`：完整棋谱。
- `capture.json`：镜头时间线、棋局事件、原始录制规格及代码版本。
- `verification.json`、`contact-sheet.jpg`：成片验证与抽帧总览。

大型录像产物保存在本机输出目录，不进入 Git；脚本、分镜、配乐生成方法及验证流程随仓库保存。再次制作会覆盖该目录中的同名产物。`node tools/promo/capture.mjs --preview` 可只录制片头来检查设备和字幕，此模式不能运行完整对局验证。

## 对局与分镜

片头展示木质棋室、模型人物和桌面道具，然后从执黑选边开始逐手交锋。中盘展示机械钟暂停与恢复、沙漏收回一轮落子、古籍战术提示，再进入俯览收官。最终黑方第 21 手完成五子连珠，呈现盖印仪式和从第 0 手到末手的复盘。

黑方通过真实触屏事件按预先搜索得到的合法棋谱落子；白方由游戏内 AI Worker 实时搜索应手，棋力为深度 2。为便于重录，录制时关闭 AI 同分候选的随机选择，黑方参考棋谱以深度 3 搜索生成。每次落子均经过原有规则引擎、人物携子动作和棋盘动画，录制脚本逐手核对 AI 应手及胜负。视频中有一次明确展示的悔棋，所以共拍摄 23 次落子，最终棋谱保留 21 手。

所有对局着法都在镜头内依次呈现，功能特写安排在轮到黑方、没有待落棋子时。字幕与电影镜头只用于录制合成。采用游戏的高画质材质、泛光及抗锯齿，录制时使用 1024 阴影贴图和 SMAA，以减少编码与渲染争用。输出为恒定 30 fps；实时录制的源帧率取决于显卡和编码器，实际采集帧率记录在验证报告中。

## 声音与来源

棋子、棋钟、毛笔、沙漏和印章音效直接录自游戏的 Web Audio 输出。背景是录制脚本原创合成的轻量五声音阶旋律，没有使用外部商业音乐。KayKit 人物、Poly Haven 场景模型和字体来源见 [素材清单](ASSET_CREDITS.md)。

验证脚本重放棋谱确认只能在最后一手结束，核对 23 次录像落子事件及一次悔棋，检查 MP4 分辨率、编码、音轨、完整解码、意外黑屏和音量，并生成抽帧总览供目视复核。
